# Сезонний попит за напрямками

Пошуки та бронювання готелів за напрямками: весна, літо й осінь 2026.

Звіт: https://alisa-product.github.io/season_directions/

## Що всередині

- `index.html` — звіт: ключові, проблемні й сезонні напрямки для переговорів про ціну, місця, які шукають, але не бронюють, і топ напрямків за сезонами.
- `data/` — таблиці, з яких побудовано звіт, у форматах JSON і CSV (CSV відкривається в Excel).

| Файл | Що в ньому |
| --- | --- |
| `summary` | Підсумки за рік: запити, броні, конверсія, місця без жодної броні |
| `seasons` | Підсумки за кожним сезоном |
| `season_top` | Топ-15 місць за запитами в кожному сезоні зі статусом |
| `key_destinations` | Ключові напрямки |
| `problem_destinations`, `problem_seasons` | Проблемні напрямки за рік і за сезонами |
| `seasonal_destinations` | Сезонні напрямки |
| `not_booked_places` | Місця, які шукають, але майже не бронюють |
| `resort_areas` | Курортні регіони |
| `countries` | Конверсія за країнами |
| `long_tail`, `never_booked` | Країни довгого хвоста та їхні місця без жодної броні |

## Як рахували

- **Запит** — один агент шукає одне місце на одну дату заїзду; повторні пошуки тієї самої поїздки рахуються один раз.
- **Броні** — унікальні замовлення.
- **Конверсія** — броні, поділені на запити; порівнюється із середньою по платформі за той самий сезон.

Повна методологія — на вкладці «Методологія» у звіті. Джерело даних — вивантаження з Amplitude за сезонами.
